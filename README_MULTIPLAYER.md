# Fall of Flags - Multiplayer Setup

## Локальный запуск сервера

### Установка зависимостей
```bash
npm install
```

### Запуск сервера
```bash
npm start
```

Сервер запустится на `ws://localhost:3000`

---

## Использование в игре

### Хост (игрок 1)
1. Откройте сайт в браузере
2. Нажмите ⚙️ → **Online Info** → **🏠 Хост**
3. Вы получите **10-значный PIN код** (например: 1234567890)
4. Поделитесь этим кодом с игроком 2

### Гость (игрок 2)
1. Откройте тот же сайт в другом браузере/устройстве
2. Нажмите ⚙️ → **Online Info** → **👥 Гость**
3. Введите **10-значный PIN код** от хоста
4. Нажмите **OK**

### Что происходит автоматически
- Оба игрока подключаются к сигнализационному серверу
- Сервер создаёт WebRTC-соединение через STUN-сервер Google
- Все переговоры (offer, answer, ICE) решаются автоматически
- Текущее состояние синхронизируется через DataChannel

## Объяснение кнопок в меню онлайн

### Основные кнопки
- **🏠 Хост**: Создает новую сессию мультиплеера. Генерирует 10-значный PIN-код для подключения второго игрока. После нажатия отображается PIN и статус сессии.
- **👥 Гость**: Позволяет присоединиться к существующей сессии. Требует ввода 10-значного PIN-кода от хоста.
- **Отключить**: Завершает текущую мультиплеер-сессию и возвращает в одиночный режим.

### Селекторы настроек
- **Выбор сложности**: Определяет уровень ИИ для игры. Доступны: Easy (случайные ходы), Normal (умные ходы), Hard (стратегия и альянсы).
- **Выбор набора стран**: Выбирает регион стран для игры: Global (все страны), East EU (Восточная Европа), NATO (страны НАТО), EU (Европейский Союз).

### Статус и информация
- **Статус подключения**: Показывает текущее состояние (Оффлайн/Онлайн).
- **Режим**: Указывает, играете ли вы локально или в мультиплеере.
- **Сложность**: Текущий выбранный уровень сложности.
- **Язык**: Выбранный язык интерфейса.

### Дополнительные кнопки
- **Закрыть**: Закрывает окно онлайн настроек без изменений.
- **Отправить состояние**: Синхронизирует текущее состояние игры с подключенным игроком (для отладки).

---

### Server.js
- Создает WebSocket сервер на порту 3000
- Управляет сессиями по PIN-кодам
- Релишует предложения (offer/answer)
- Материляет ICE-кандидатов
- Синхронизирует состояние игры

### Client (index.html)
- Подключается к сигнализационному серверу
- Создает RTCPeerConnection с STUN-серверами
- Отправляет/получает SDP автоматически
- Использует DataChannel для передачи действий

---

## Возможные проблемы

### Сервер недоступен
- Убедитесь, что Node.js запущен: `npm start`
- Проверьте адрес `SIGNALING_SERVER` в index.html

### Не подключаются за NAT
- Используются STUN-серверы Google (бесплатно)
- Для сложных сценариев нужен TURN-сервер

### Код не подходит
- PIN чувствителен к регистру
- Проверьте ровно 10 цифр
